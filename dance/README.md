# Clawd ダンス

Claude Code のドット絵キャラクター（Clawd）が踊るだけの Web アプリです。
ビルドやインストールは不要で、`index.html` をブラウザで開けば動きます。

## 操作

- **ゆらゆら / ジャンプ / 手ふり**: 踊りを切り替えます
- **なでる**: Clawd の上でドラッグ（スマホは指でこする）して左右に往復させると、目が ^ ^ になり、ハートを出して喜びます。
  手を離すと少しして踊りに戻ります。音楽 ON のときは喜ぶ音も鳴ります
- **なかよし度**: 1往復なでるごとに +1（最大 100）。ブラウザに保存され、次に開いたときも引き継ぎます
  - 30〜: なで終わったあと手をふって見送る
  - 60〜: なで終わったあとくるっと回っておじぎ
  - 100: ふだんからほっぺがピンクになる
- **♪ 音楽 ON / OFF**: ブラウザ内で生成したリズムとメロディを鳴らします（テンポ120）。
  ブラウザの制約で、ボタンを押すまで音は鳴りません

## ファイル

- `index.html` … 画面とキャラクターの SVG
- `style.css` … 見た目と踊りのアニメーション（1拍 = `--beat` = 0.5秒）
- `script.js` … ボタン操作、なでる判定となかよし度、Web Audio API による音の生成
